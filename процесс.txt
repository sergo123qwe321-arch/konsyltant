Журнал прогресса проекта «ИИ-Консультант RAG API» (Маленькая Страна)
Релиз: v7.0-production
Дата: 25 августа 2026

Текущее состояние:
1. Завершены и верифицированы блоки А, Б, В, Г, Д.
2. Блок А (Кабинет врача):
   - Просмотр/скачивание оригинальных диагностических файлов через GET /api/v1/doctor/patient-records/{share_token}/document/{filename} (inline/blob).
   - Заметки врача: таблица doctor_notes, B-tree индекс, полный CRUD API, интерфейс заметок с автосохранением в дашборде.
   - Клинический консилиум: RAG-генерация резюме, структурированные карточки (анамнез, диагнозы, противопоказания красным, препараты янтарным, рекомендации), скачивание отчета в формате PDF.
3. Блок Б (Локальное хранилище медиа):
   - POST /api/v1/admin/upload сохраняет файлы локально в static/uploads/ для прямой раздачи Nginx.
   - Исключение static/uploads/* добавлено в .gitignore.
   - В docker-compose.yml подключен том uploads_data.
   - Выполнена миграция старых ссылок на обложки в базе данных.
4. Блок В (Гибридный видеоплеер):
   - Локальные видео через HTML5 video с постером.
   - Внешние ссылки через iframe без автоплея.
   - Под каждым плеером текстовая ссылка «Смотреть на первоисточнике».
5. Блок Г (Открытый чат сообщества):
   - Публичное чтение GET /api/v1/public/chat.
   - Отправка сообщений POST /api/v1/public/chat для авторизованных (PATIENT, DOCTOR, ADMIN) с Rate Limiting (10 сообщений/мин).
   - Цветовая маркировка: Родители — зеленый, Врачи — красный, Администрация — фиолетовый.
   - Три точки входа для логина на лендинге. Модерация администратором.
   - Ноль ИИ-токенов в открытом чате.
6. Блок Д (Тестирование и суверенитет):
   - 85/85 тестов пройдено со 100% успехом.
   - Автоматический аудит подтвердил 0 упоминаний обходных средств (vpn) по всему проекту.
