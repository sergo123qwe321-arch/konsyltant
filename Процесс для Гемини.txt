# Памятка для ИИ (Гемини) по проекту Консультант

## Сеть и Почта на Render.com / VPS Beget
- **Порт SMTP**: СТРОГО использовать порт 465 (`SMTP_SSL` с контекстным менеджером и таймаутом, например 15 секунд). Порт 587 (starttls) зависает и не работает на некоторых облачных хостингах.
- **IPv4**: При необходимости принудительно использовать `socket.AF_INET` через патчинг `socket.getaddrinfo`, если возникает ошибка "Network is unreachable" из-за IPv6.

## Базы данных
- **PostgreSQL / SQLite**: Используем гибридную архитектуру в `database.py`. Если есть `DATABASE_URL`, подключаемся к Postgres через `psycopg2`. Если нет — к `konsyltant.db` через `sqlite3`.
- **URL Postgres**: Автоматическая адаптация схемы `postgres://` -> `postgresql://`.

## Аутентификация и Сессии
- **Stateless JWT**: Глобальный словарь `SESSIONS` полностью удален из `main.py`. Все сессии работают через подписанные JWT-токены (`PyJWT`, алгоритм `HS256`, срок жизни 30 минут по умолчанию). В payload токена передаются `sub` (токен доступа) и `allowed_folder` (ID папки на Диске). Внедрена FastAPI Dependency `get_current_patient` для защищенных маршрутов, а также верификация роли `ADMIN` для `/api/v1/admin/*`.

## Инфраструктура и Nginx
- Nginx reverse proxy проксирует `/` и `/app/` на `http://web:8000/`, раздает `/static/` напрямую.
- Домен в Punycode: `xn--g1aj3a.site` (цмз.site).
- SSL сертификаты: Let's Encrypt + certbot контейнер. Fallback генерация сертификата через `nginx/init-ssl.sh`.
