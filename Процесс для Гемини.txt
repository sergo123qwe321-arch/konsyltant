# Памятка для ИИ (Гемини) по проекту Консультант

## Сеть и Почта на Render.com
- **Порт SMTP**: СТРОГО использовать порт 465 (`SMTP_SSL` с контекстным менеджером и таймаутом, например 15 секунд). Порт 587 (starttls) зависает и не работает на облачных хостингах вроде Render.
- **IPv4**: При использовании SMTP на Render необходимо принудительно использовать `socket.AF_INET` через патчинг `socket.getaddrinfo`, иначе возникает ошибка "Network is unreachable" из-за IPv6.

## Базы данных
- **PostgreSQL / SQLite**: Используем гибридную архитектуру в `database.py`. Если есть `DATABASE_URL`, подключаемся к Postgres через `psycopg2`. Если нет — к `konsyltant.db` через `sqlite3`.
- **URL Postgres**: Render выдает URL в формате `postgres://...`, который не поддерживается современными ORM/драйверами в Python. Для надежности всегда делаем `.replace("postgres://", "postgresql://", 1)`.

## Деплой
- **Засыпание**: Бесплатный тариф Render засыпает через 15 минут. Используем внутренний `keep-awake` поток, который пингует `BASE_URL`.
