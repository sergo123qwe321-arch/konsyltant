# Служебные скрипты проекта (Scripts Directory)

В этой директории собраны вспомогательные административные и отладочные скрипты. Все скрипты в этой папке исключены из продакшен Docker-образа через .dockerignore.

---

## 📁 Структура директории

### 1. scripts/admin/ — Административные утилиты
- **
eset_db.py**: Утилита для выборочного сброса / очистки тестовых записей в локальной базе данных SQLite. 
  > ⚠️ **ВНИМАНИЕ:** Предназначено **ТОЛЬКО** для локальной разработки. **НЕ** использовать на боевом сервере (Production).

### 2. scripts/debug/ — Инструменты ручной отладки
- **inspect_timur_folder.py**: Скрипт для проверки доступности и структуры конкретной папки на Яндекс.Диске через REST API.
- **inspect_yandex_disk_files.py**: Инструмент для ручной инспекции содержимого и прямых ссылок файлов на Яндекс.Диске.
  > ℹ️ **ПРИМЕЧАНИЕ:** Скрипты отладки не импортируются в основном коде бэкенда и служат для ручной диагностики интеграций разработчиком.
