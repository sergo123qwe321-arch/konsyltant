# Цифровая платформа «ИИ-Консультант Центра Ментального Здоровья» (Маленькая Страна)

## 1. Концепция и общественная значимость
Платформа решает проблему раннего выявления нарушений развития у детей (речевых, неврологических, поведенческих) и снижает барьер между родителями и профильными врачами. 
- **Для общества:** ранний скрининг рисков, снижение нагрузки на первичное звено медицины, повышение доступности квалифицированной помощи независимо от региона.
- **Для родителей:** персональный ассистент 24/7, перевод сложных клинических диагнозов на доступный язык, хранение всей истории ребенка в одном месте и голосовой ввод вопросов без барьеров.
- **Для врачей:** сокращение времени на первичный анализ анамнеза на 70–80%. ИИ мгновенно формирует структурированное резюме по десяткам страниц выписок, подсвечивает противопоказания и строит динамику анализов.

## 2. Ключевой функционал платформы
1. **Интеллектуальный RAG-консилиум:** изолированная работа с документами конкретного ребенка без риска утечки в общий контекст.
2. **Гибридный OCR-парсер:** оцифровка разнородных медицинских документов (PDF, сканы, фото заключений, выписки).
3. **Безопасный шеринг (Doctor Portal):** временные ссылки с ограниченным TTL (24–48ч) и жестким лимитом (не более 2 активных доступов на карту).
4. **Клинический суммаризатор и генератор отчетов:** автоматическая сборка официальных PDF-заключений и динамики лабораторных показателей.
5. **Модерируемое сообщество:** открытый канал для родителей и экспертов с автоматической защитой от спама, мата и непроверенных ссылок.

## 3. Архитектура безопасности и соответствие 152-ФЗ
Безопасность платформы построена по принципу Zero-Trust и строго соблюдает законодательство РФ о персональных и медицинских данных:
- **100% Отечественный контур:** сервера и обработка строго в юрисдикции РФ. Никаких зарубежных облачных API.
- **Изоляция данных (Data at Rest):** база данных хранит только хэши и токены маршрутизации; медицинские данные шифруются по стандарту Fernet (AES-128).
- **Stateless-аутентификация:** токены JWT со строгим временем жизни (30 мин) и мгновенный отзыв доступов.
- **Защита периметра:** аппаратный Rate Limiting против перебора паролей (блокировка после 5 неудачных попыток), маскирование IP-адресов.
- **Непрерывность бизнеса:** автоматические ежедневные бэкапы БД со сквозным шифрованием и мониторинг целостности данных.

## 4. Стек технологий
- **Бэкенд:** Python 3.13, FastAPI, PostgreSQL, Nginx.
- **ИИ-ядро:** Отечественная LLM GigaChat API (Сбер) по защищенному каналу.
- **Обработка документов:** Tesseract OCR (локальный контур), ReportLab, python-docx.
- **Клиентская часть:** Vanilla JS/HTML5, Web Speech API (локальное распознавание голоса на устройстве пользователя).
